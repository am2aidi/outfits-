# HURANOW — Fit, Wear, Buy

> **Stealth Luxury & Athletic Performance Store**  
> Inspired by the bold, minimalist aesthetic of **Nike**, featuring an interactive **Real Mannequin Fitting Studio** where customers can fit outfits on live models and buy complete looks in one click.

---

## ⚡ Core Features

- **Nike-Inspired Dark Aesthetic**: Deep stealth blacks (`#080808`, `#0e0e11`), bold high-contrast condensed typography, subtle border treatments, and smooth transitions.
- **Demographics Coverage**: Dedicated categories and filters for:
  - **Men** (Track jackets, windrunners, carbon road racing shoes, tactical utility cargos)
  - **Women** (Seamless sculpt compression sets, platform sneakers, luxury trench track coats)
  - **Kids (5–14Y)** (Reflective speed tracksuits, flex-blade runners)
  - **Baby & Toddler (0–4Y)** (100% GOTS certified organic soft-flex rompers, sensory pre-walkers, calming balms)
- **Interactive Live Mannequin Studio (Fitting Room)**:
  - Real human model/mannequin bases for Men, Women, Kids, and Baby.
  - Mix & match tops, bottoms, shoes, headwear, eyewear, and bags.
  - Live mannequin tags indicating equipped gear.
  - Sizing selector for both apparel and footwear.
  - **1-Click "Add Entire Fit to Bag"** action.
- **Product Details & Quick-View Modal**:
  - Image gallery switcher.
  - Size selectors and technical performance specs.
  - Direct "Try on Mannequin" link.
- **Cart Slide-Over Drawer**:
  - Dynamic free delivery threshold meter (Free over RWF 100,000 / $80).
  - Promo code engine (`HURANOW10` for 10% off).
  - Real-time quantity management and subtotal calculation.
- **Multi-Method Instant Checkout**:
  - **MTN MoMo** (Mobile Money USSD push notification)
  - **Airtel Money**
  - **Visa & Mastercard** (with live card number formatting and security checks)
  - Instant order receipt generation (`HN-XXXXXXXX`) with celebration confetti!
- **Dual Currency Switcher**:
  - **RWF** (Rwandan Franc)
  - **USD** ($)
  - **EUR** (€)
- **Authentication & Membership**:
  - Seamless sliding login/signup card with SHA-256 client password hashing and local persistence.

## 🛠️ Tech Stack

- **React 19**
- **Vite**
- **Tailwind CSS v4** (`@tailwindcss/vite`)
- **Lucide React** (Athletic icon set)
- **Canvas Confetti** (Checkout celebration)

## 🚀 Running Locally

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Open your browser at:
   ```
   http://localhost:5173
   ```

4. Build for production:
   ```bash
   npm run build
   ```
